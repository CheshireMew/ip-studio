# 通用离散状态式宠物生产

本文件用于 Codex 之外的桌面助手、应用宠物和其它有限状态式 2D 宠物，也提供所有平台适配器共享的生产原则。平台固定状态、尺寸、图集布局、manifest 和安装路径留在对应适配器中。

## 从真实运行时建立宠物合同

先读取目标运行时真正产生和消费的状态：什么事件让宠物待机、移动、等待、工作、完成或失败，方向来自指针、移动、摄像机还是根本不存在，最终由哪个加载器读取哪些文件。宠物合同只包含这些真实状态、方向、帧数、事件时点、画布、锚点和导出格式；不从某个已有平台反推通用动作清单。

没有内置适配器时，使用兄弟 `$motion-studio` 的合同、整表生成、透明处理、图集和 manifest 能力。Pet Studio 在此基础上增加宠物行为语义、角色尺寸适配、运行历史、方向检查和用户点名的平台接入。目标格式需要新的确定性打包器或安装器时，先把它作为平台适配器的具体文件范围与外部影响交给用户确认。

## 身份、提示词和运行记录

每次运行绑定锁定角色的 ID、revision、档案哈希和主参考图哈希。主参考图负责身份，目标项目素材负责平台和交互事实，布局图只负责固定格数、顺序和安全边距；它们的维护信息不进入创作提示词。

一个图像任务只保留一条实际提示词。完整用户提示词原样使用；否则只写当前动作或方向目标、原始材料、参考职责、固定帧数与顺序、画布或幕布协议和用户硬要求。动作细节、构图和视觉表达由图像模型根据角色与状态决定。生成后的语义、连续性、透明度和几何检查不提前扩成负面清单塞回提示词。

运行记录保存已确认的提示词和图片顺序、正式生成结果、确定性处理报告、预览、角色来源、合同哈希和成品包。修复从最早失败的完整任务重新开始，旧任务和依赖产物进入历史；不覆盖已完成运行，也不把失败图作为新的身份参考。

## 生产、检查和接入

同一状态或方向组在一张图中生成完整帧序列，随后用确定性程序切格、统一缩放、锚点对齐、透明处理和拼装。程序不替换角色内部像素。实际打开动作条、透明帧、图集和无损循环预览，确认角色身份、动作含义、顺序、尺度、基线、连接件和背景。

方向输入连续变化时按主入口选择的方向动画方法检查；只有离散的左、右或四向移动时，按真实方向合同检查即可。最终包必须让正式生产者、manifest 和消费者使用同一状态与方向名称。只交付素材时停止在经过检查的宠物包；请求包含接入时，继续让真实状态生产者驱动真实消费者，并观察目标尺寸下的结果。

安装或替换外部产品文件时，先解析准确目标。相同内容不重复写入；同名不同内容在获批后备份现有安装，使用同目录暂存和原子替换，失败时恢复。不要删除旧角色版本、正式运行记录或旧安装备份。
