# 宠物方向动画 QA

只在目标运行时连续消费宠物朝向或注视方向时使用。它负责生成后的方向语义与连续性检查，不扩写生图提示词。

## 建立方向依据

先根据角色真实构造说明固定锚点，以及眼睛、眼睑、头颈、上身、耳朵、尾巴和配件怎样共同表达方向。固定点通常是脚、底座或下躯干；佩戴、手持和悬挂配件必须保持连接，并按自身刚柔性连续跟随。

先取得上、屏幕右、下、屏幕左四个基准方向，在宠物正常显示尺寸下检查。脸部角色根据眼睛、鼻口、头部和上身的整体朝向判断，非脸部角色使用自然指向部位。屏幕左右始终是观看者坐标。任何基准方向错误或无法判断，都先修正该方向依据。

## 生成连续方向组

根据运行时需要的实际方向数量和顺序生成一组连贯姿态。Codex v2 使用顺时针十六方向与两条八格方向行；其它平台遵守自己的合同。相邻姿态应共享身份、尺度、基线和固定锚点，并沿同一运动机制逐步变化。完整方向组一起生成和注册，不能用独立重画或局部粘贴的一格混入正式序列。后续方向组必须服从已经批准的尺度和注册；无法装入时重做后续方向组，不能缩放或改写已批准的前一组。

## 正常尺寸检查

在最终显示尺寸建立带标签方向总览，并逐项记录预期方向、实际可见方向和判断依据。再检查所有相邻方向，包括序列首尾和跨行边界：不能出现方向反转、错误象限、明显跳位、缩放跳动、身份变化、配件断裂、裁切或透明孔洞。

需要排除标签暗示时，使用随机 A/B 方向图让三个没有看过标签、提示词或答案的独立看图执行者分别判断水平或垂直方向，再按严格多数合并。没有独立执行者时由用户看图，不伪造三份结论。

四个基准方向是硬门槛。中间方向的盲审分歧或细微程度不足先记为警告；只有带标签的正常尺寸检查确认错误象限、反转或明显连续性破坏时才判失败。数值连续性报告只提供检查线索，不能代替实际观看。

## 修复

基准方向失败时修正相应基准；正式方向序列中任一格失败时重做包含它的完整方向组。提示词或图片输入发生变化时重新展示并等待确认。修复后重新执行注册、方向总览、相邻连续性和必要的独立方向检查，已经通过的身份、尺度和连接关系不能退化。
