# OKX Editorial 视觉语言

这套内置资源用于带有已锁定 IP 角色的主页横幅、资料卡、文章封面、说明图和正文插图。它提供视觉语法，不提供当前作品的事实、文案或构图成品。

## 固定视觉语法

- 背景以 `#000000` 和 `#1A1A1A` 为主，白色 `#FFFFFF` 承担主标题与关键对象，灰色 `#8C8C8C` 承担次级说明。
- 核心强调色使用霓虹黄绿色 `#BBFF2F`。它只标记关键词、关键数字、路径、按钮或少量环境反射，不铺满整张图。
- 标题使用超大、紧凑、几何感无衬线字；说明文字短而疏。细分隔线、网格、小标签和角标只帮助阅读。
- 构图通常是不对称分屏：一侧给出一句结论，另一侧用一个主要视觉证据支持它。小号白色 OKX 标记位于左上安全区。
- 信息层级依次为标题或关键数字、主要视觉证据、必要说明、来源或免责声明。缩略图里仍应先看到前两层。

## 四种可选主场景

根据内容只选一种，不把四种模式叠在同一张图里。

1. 真实界面或产品使用：适合已有界面截图、功能路径和产品操作。没有真实资料时不虚构产品页面。
2. 金属质感的抽象基础设施：适合链、资金、算力、数据和系统关系。用深色金属、银灰结构与少量绿色能量路径表达。
3. 黑白摄影与荧光点色：适合地点、活动与文化主题。照片保持灰阶，只让少数地标、灯光或路径出现绿色。
4. 角色驱动的活动场景：适合邀请、里程碑和社区活动。IP 角色承担动作，场景提供空间证据，版式仍保持黑、白、绿的清楚层级。

## IP 角色融合

角色主参考图决定脸、轮廓、比例、服装连接、颜色落点和标志物。当前内容决定动作、尺度、透视和场景位置。角色不能作为最后贴上的立绘：身体要与物体发生接触或遮挡，并共享同一主光、绿色环境反射、景深、颗粒和落地阴影。边缘保留自然的明暗过渡与环境染色；出现白边、毛边、漂浮感或与背景不同的清晰度时，直接判为未通过。

## 参考资料的使用边界

七张案例只校准配色职责、标题尺度、信息密度、留白、分屏、材质和品牌标记位置。不要复制案例中的文案、数字、行情、手机界面、地点、角色、吉祥物、物件组合或整套构图。透明 OKX 标记是唯一品牌标记真源；使用原始图片输入，不重画、不拼字，也不改变方块关系。

## 出图检查

- 缩略图：标题或数字、角色动作、主要对象是否按这一顺序被看到；绿色是否只落在真正关键处。
- 100%：角色边缘、发丝、耳朵、肢体与服装是否干净；接触阴影、遮挡、反射、透视和颗粒是否与环境一致。
- 内容：所有可见文字、数字、专有名词和界面都能回到当前内容真源或用户资料。
- 品牌：OKX 标记来自透明资产，比例正确、位置克制，没有生成式变形。
- 结构：只有一个主要场景、一条阅读路径和一个视觉中心。
