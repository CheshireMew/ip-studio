# 极简手绘视觉参考

本目录中的四张完整案例来自 [Ian Xiaohei Illustrations](https://github.com/helloianneo/ian-xiaohei-illustrations)，作者 Ian，按 MIT License 使用。

这些图片只用于校准以下视觉属性：

- 白底与大面积留白
- 细而略带手绘感的黑色线条
- 黑色主体与少量强调色的职责分工
- “角色执行动作、物体承载关系”的场景组织方式
- 极少、极短的手写式标签

不要临摹案例中的具体构图、物体组合、文案或隐喻。生成新作品时，应从当前内容重新提炼动作、物体与因果关系。

上游项目的 `NOTICE.md` 希望衍生文档保留项目名称或注明来源，因此本说明与图片一同保留。
